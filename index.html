  1. 01

    SafeSign PhysicalAI

    2026.09 – 104인 팀AI 비전 · 평가 · 통합

    크레인 수신호 7종을 카메라로 판정하고, 결과를 로봇 손·micro:bit·주행 로봇의 동작으로 돌려주는 교육 시스템입니다.

    문제
    공개 데이터만으로 학습해야 했고, 판정은 라즈베리파이 5 CPU에서 실시간으로 돌아야 했습니다. 처음 보는 손 모양을 틀리게 판정하지 않는 것도 중요했습니다.
    내 역할
    • 비전 파이프라인 설계·모델 학습
    • 데이터 분할·평가 전략 설계
    • 판정 성능 측정·검증
    • 웹 백엔드 판정 로직 구현
    • 1차 통합 병합·저장소 구성
    기술
    MediaPipe · SVM · Raspberry Pi 5 · FastAPI · Supabase · Docker Compose
    결과
    학습에 쓰지 않은 210회 평가에서 정답률 95.2% · Macro F1 0.974 · 오분류 0건(95% 상한 1.8%)

    핵심 장면 · 정답률 98.81%가 데이터 누수 때문에 생긴 허수임을 찾아 세션 단위 분할로 다시 평가했습니다.

    상세 보기 GitHub AI 비전 보고서 모델 카드
  2. 02

    독거노인 관리 시스템

    2025.03 – 2026.024인 팀졸업 작품 · 음성 비서 · 낙상 알림

    카메라와 마이크로 혼자 사는 노인을 지켜보다가 넘어지면 바로 알리고, 음성으로 말을 걸면 답해 주는 말벗 AI 스피커입니다.

    문제
    65세 이상 인구가 20.4%(2025.03)에 이르고 고령자 1인 가구가 늘지만, 복지 지원은 지역에 따라 사각지대가 있습니다.
    내 역할
    • 음성 비서 시스템 전체(호출어·STT·RAG 답변·TTS)
    • 낙상 감지와 휴대폰 푸시 알림(03에서 자세히)
    기술
    Google Cloud STT/TTS · Porcupine · Gemini · 웹 검색 RAG · MoveNet(TFLite) · Firebase Cloud Messaging
    설계
    클라우드 음성 합성·인증이 실패해도 스피커가 멈추지 않도록 단계별 대체 경로를 두었습니다.

    핵심 장면 · 노인의 부정확한 발음도 알아듣도록, 오프라인 키워드 감지와 비슷한 발음 목록에 가중치를 준 STT를 결합한 하이브리드 호출어 인식을 만들었습니다.

  3. 03

    카메라 낙상 감지

    2025.03 – 06졸업 작품규칙 판정 → 학습 모델

    졸업 작품의 낙상 감지를 맡아, 규칙 기반 판정에서 학습 모델 후보까지 세 가지 방식으로 만들어 봤습니다.

    문제
    넘어지는 순간은 놓치지 않으면서, 앉기·눕기 같은 일상 동작에는 알리지 않아야 했습니다.
    내 역할
    • 배경 차분 규칙 → MoveNet 관절 2단계 판정
    • MobileNetV2 + LSTM 학습 모델 후보
    • FCM 휴대폰 알림
    기술
    OpenCV · MoveNet(TFLite) · TensorFlow/Keras · MobileNetV2 · LSTM · UBFC 데이터셋
    결과
    학습 모델 후보 검증 정확도 99.42% (영상 클립 무작위 분할 · 시험셋 없음)

    배운 점 · 같은 장소·인물이 학습과 검증에 섞일 수 있는 분할이었습니다. 이 경험이 SafeSign에서 세션 단위 평가를 고집한 이유가 됐습니다.
