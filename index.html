  1. 01

    SafeSign PhysicalAI

    2026.09 – 104인 팀AI 비전 · 평가 · 통합

    크레인 수신호 7종을 카메라로 판정하고, 결과를 로봇 손·micro:bit·주행 로봇의 동작으로 돌려주는 교육 시스템입니다.

    문제
    공개 데이터만으로 학습해야 했고, 판정은 라즈베리파이 5 CPU에서 실시간으로 돌아야 했습니다. 처음 보는 손 모양을 틀리게 판정하지 않는 것도 중요했습니다.
    내 역할
    비전 파이프라인 설계·학습, 데이터 분할 전략, 판정 성능 측정, 웹 백엔드 판정 로직, 1차 통합 병합
    기술
    MediaPipe · SVM · Raspberry Pi 5 · FastAPI · Supabase · Docker Compose
    결과
    정답률 95.2% · 오분류율 0.0% · Macro F1 0.974 (팀원 3명 촬영 210시도, 학습 미사용)

    핵심 장면 · 정답률 98.81%가 데이터 누수 때문에 생긴 허수임을 찾아 세션 단위 분할로 다시 평가했습니다.

  2. 02

    AI 스피커 + 낙상 알림

    2025.03 – 06졸업 작품

    웨이크워드로 부르는 한국어 음성 비서와, 웹캠으로 낙상을 감지해 휴대폰으로 알리는 기능을 한 프로그램에서 동시에 실행합니다.

    문제
    음성 인식·답변 생성·음성 출력과 영상 낙상 감지를 한 장치에서 함께 돌리고, 넘어진 순간을 바로 알려야 했습니다.
    내 역할
    음성 비서, 낙상 감지, 푸시 알림 모듈 구현
    기술
    Google Cloud STT/TTS · Gemini · 웹 검색 결합 답변 · MoveNet(TFLite) · Firebase Cloud Messaging · Android
    개선
    1차 버전의 배경 차분 + 가로세로 비율 판정을, MoveNet 관절 좌표로 "의심 → 확인" 2단계 판정으로 바꿨습니다.

    핵심 장면 · 한 번 크게 움직였다고 바로 알리지 않도록, 의심 뒤 4프레임 안에 몸이 수평이고 코가 엉덩이보다 아래일 때만 낙상으로 확정합니다.

  3. 03

    영상 시퀀스 낙상 감지

    2025.06개인

    사전학습 MobileNetV2로 프레임 특징을 뽑고, 32프레임 시퀀스를 LSTM으로 분류해 웹캠 영상에서 실시간으로 낙상을 판단합니다.

    문제
    한 장의 자세가 아니라 넘어지는 "움직임"을 판단하려면 여러 프레임의 흐름을 봐야 했습니다.
    내 역할
    특징 추출, LSTM 학습, 웹캠 실시간 감지 전체
    기술
    TensorFlow/Keras · MobileNetV2 · LSTM · OpenCV · Google Colab · UBFC Fall Detection Dataset
    결과
    검증 정확도 99.42% (영상 클립 무작위 8:2 분할, 별도 시험셋 없음)

    배운 점 · 같은 장소·인물의 클립이 학습과 검증에 함께 들어갈 수 있는 분할이었습니다. 이 한계가 SafeSign에서 세션 단위 분할을 고집한 이유가 됐습니다.
