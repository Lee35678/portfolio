MY CONTRIBUTION
  • 음성 비서: 웨이크워드, Cloud STT/TTS, 웹 검색 결합 답변
  • 낙상 감지: MoveNet 관절 좌표 기반 2단계 판정
  • 알림: Firebase Cloud Messaging 토픽 푸시, 안드로이드 수신 예시
  • 런처: 음성은 백그라운드 스레드, 낙상 감지는 메인 스레드로 동시 실행

시스템 구성

음성마이크→웨이크워드 "실비야"→Cloud STT→웹 검색 상위 5개 + Gemini 종합→Cloud TTS (gTTS 폴백)→스피커
낙상웹캠→MoveNet Lightning 192×192→1단계 의심→2단계 확인→FCM fallAlerts 토픽→안드로이드 앱

"현재 시간", "종료" 같은 특수 명령은 검색 없이 기기에서 바로 처리합니다. 낙상 추론은 2프레임마다 한 번, 약 15fps 웹캠에서 7~8fps로 돕니다.

설계 판단

선택이유이전 방식
관절 좌표 + 2단계 확인

배경 차분은 사람 말고도 움직이는 모든 것에 반응하고, 한 번 크게 움직인 것만으로는 넘어졌다고 보기 어렵습니다. 의심과 확인을 나눠 한 순간의 움직임만으로 알리지 않게 했습니다.

배경 차분 + 가로세로 비율
웹 검색 결합 답변
